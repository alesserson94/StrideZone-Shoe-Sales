# StrideZone-Shoe-Sales

**Introduction**

For this project, I used Claude to generate a synthetic dataset for a fictitious shoe store chain called StrideZone. The goal of the project is to determine trends/patterns in shoe sales, and make recommendations so as to increase revenue/profit.

**Questions to Answer:**

1. Determine which products are best-selling
2. Determine which products have the most returns or cancellations
3. Which geographical region has the most sales?
4. Which store has the most revenue per square foot?
5. Compare sales among various store types (mall, outlet, flagship, etc.)
6. Compare sales among newer stores vs. older stores
7. Analyze discount percentage versus return rate (do discounted items get returned more?)

**Tech Stack Used:**

1. Python/pandas
2. MySQL (Joins, CASE statements, CTE's)
3. Excel
