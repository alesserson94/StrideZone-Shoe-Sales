# StrideZone-Shoe-Sales

## Introduction
For this project, I used Claude to generate a synthetic dataset for a fictitious shoe store chain called StrideZone. The goal of the project is to determine trends/patterns in shoe sales, and make recommendations so as to increase revenue/profit.

## Questions to Answer
1. Determine which 10 products are best-selling
2. Which payment method is used most often, and how does it vary by sales channel (online vs. in-store)?
3. Determine which products have the most returns or cancellations. Are they concentrated in specific categories, sizes, or store types?
4. Determine average discount per category.
5. Which geographical region has the most sales, and most total revenue?
6. Which store has the most revenue per square foot?
7. Compare average order value among various store types (mall, outlet, flagship, etc.)
8. Compare sales among newer stores vs. older stores
9. Analyze discount percentage versus return rate (do discounted items get returned more?)

## Tech Stack Used
1. Python/pandas
2. MySQL (Joins, CASE statements, CTE's)
3. Excel
4. Tableau
